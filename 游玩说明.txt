《盛夏往事》游玩说明
====================================================

【游戏简介】
2012 年复古风格沉浸式网页 ARG 解谜。你是「中国旧网页档案馆」的一位浏览者，
在 2012 年滨城地方网站目录最下方，发现了一个灰色的、没有被官方命名的文件夹……
全程约 60～75 分钟，建议戴上耳机，安静地玩。

【怎么开始】
方法一（推荐）：双击本目录下的「启动游戏.bat」，
    会自动启动本地服务器并打开浏览器（需要电脑装有 Python；
    声音与全部素材在本地服务器下完整可用）。
    没有 Python 时也可直接双击 index.html 试玩，但直接打开模式下
    背景音乐可能无法加载（点击音效与解谜不受影响），建议用 bat。
方法二：把整个文件夹部署到 GitHub Pages（见下方说明），用链接游玩。

【玩法提示】
· 所有谜题都在网页界面内完成，不需要、也不建议查看源代码。
· 认真阅读每个页面的文字，顺着超链接一步步走，线索全部有前置铺垫。
· 搜索引擎支持同义词模糊匹配，换个说法也能找到；想不出时，
  页面停留久了角落会出现极淡的提示。
· 相册密码和一个生日有关。
· 通关后再进游戏，会看到 2013 年的变化（进度存在本地浏览器中，
  清除浏览器数据会重置）。
· 推荐使用电脑浏览器，分辨率 1024×768 以上。

【声音说明】
· 首次点击进入后，声音会自动开启（浏览器策略，不允许未经操作自动播放）。
· 右下角有一个拟物小喇叭按钮，可随时开/关声音；你的选择会被记住，
  下次打开保持同样设置。
· 声音分场景设计：档案馆拨号上网的握手声、晚报的市井远景（自行车铃、
  叫卖、收音机底噪）、论坛的夏蝉与人气、讯聊的消息提示、相册的快门与
  解锁八音盒、医院仪器声、结尾钢琴与海浪等，每个页面都有不同的声音层。
  音量克制，建议戴耳机体验；想安静游玩可直接点喇叭静音。

【手机 / 平板】
· 已适配窄屏：手机浏览器也能正常浏览，表格可左右滑动，
  触摸即可操作，桌面端悬停才出现的彩蛋在手机上点一下同样出现。

【部署到 GitHub Pages】
1. 在 GitHub 新建一个仓库，把本文件夹内「所有文件」上传到仓库根目录；
2. 仓库 Settings → Pages → Source 选择 main 分支、根目录（/），保存；
3. 稍等 1～2 分钟，打开 https://你的用户名.github.io/仓库名/ 即可游玩。
   游戏全部使用相对路径，放在子目录下也能正常运行。
